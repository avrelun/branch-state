## Gruvbox palette

The branding uses five color values from [Gruvbox](https://github.com/morhetz/gruvbox), by **Pavel Pertsev (morhetz)**. Gruvbox's palette is not claimed as original Branchstate work. The Branchstate mark geometry and preview composition were prepared separately; no Gruvbox logo, screenshot, font, or theme implementation is included.

Source revision checked on September 27, 2026: `ef8864bb42bf244f0295d1c5a403b27e3d139695`.

- [Palette definitions](https://github.com/morhetz/gruvbox/blob/ef8864bb42bf244f0295d1c5a403b27e3d139695/colors/gruvbox.vim)
- [Upstream author and MIT license declaration](https://github.com/morhetz/gruvbox/blob/ef8864bb42bf244f0295d1c5a403b27e3d139695/package.json)
- [Upstream README: MIT/X11](https://github.com/morhetz/gruvbox/blob/ef8864bb42bf244f0295d1c5a403b27e3d139695/README.md#license)

| Value | Upstream palette name | Use |
| --- | --- | --- |
| `#282828` | `dark0` | Background |
| `#ebdbb2` | `light1` | Primary text |
| `#b8bb26` | `bright_green` | Branches and nodes |
| `#d79921` | `neutral_yellow` | Accent |
| `#bdae93` | `light3` | Secondary text |
